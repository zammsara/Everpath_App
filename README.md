# Everpath

Everpath es una aplicación Android de crecimiento personal que permite visualizar la vida del usuario como un mapa interactivo.

## Arquitectura

- Clean Architecture
- MVVM
- Offline First

## Tecnologías

### Android

- Kotlin
- Jetpack Compose
- Room
- Hilt
- Retrofit
- Coroutines

### Backend

- Spring Boot
- PostgreSQL
- JWT
